Configuración

Todo lo que la app usa para operar, editable sin tocar código.

Empresa

Atajos de teclado (punto de venta)

Tocá la tecla actual y después presioná la que quieras usar. Evitá letras/números sueltos — el lector de código de barras los usa; F1-F12, Delete, Escape, etc. son más seguros.

Sincronización en vivo entre cajas

Para cuando varias cajas venden al mismo tiempo: comparten el mismo stock, no repiten número de ticket, y si se corta la conexión en una caja, esa caja sigue vendiendo sola y se pone al día apenas vuelve internet. Usa Firebase (Google) — gratis, sin tarjeta, no se duerme por inactividad.

Respaldo manual (copia de seguridad completa)

Copia manual de todo (catálogo, ventas, clientes, config) a tu base de Supabase, en un solo sentido por vez — "Subir" pisa la nube con lo de este dispositivo, "Bajar" pisa este dispositivo con lo de la nube. Sirve como respaldo o para copiar todo a una caja nueva. Para que varias cajas convivan vendiendo al mismo tiempo, usá la tarjeta de arriba en cambio.

Lectura de facturas por foto (IA)

Usa el mismo Worker de ARCA, con una ruta aparte (/leer-factura) que necesita su propia API key de Anthropic (console.anthropic.com, con costo por uso) cargada como secret en el Worker.

Facturación electrónica (ARCA)

Requiere el Worker de ARCA desplegado aparte (ver README-ARCA.md). El punto de venta tiene que estar habilitado en ARCA para Web Services (no manual).

Sucursal

Impuestos

Los precios de venta se consideran finales (IVA incluido), como se opera de cara al público. El IVA se discrimina hacia adentro para los reportes.

Punto de venta

Condiciones de pago (tarjetas y medios)

Equivalente a "Tipos de condición de pago" de POSBerry: cada tarjeta/medio con su tipo y cuotas con coeficiente (1.10 = 10% de recargo). Se usan como referencia de pago dentro del método "Débito/Crédito" al cobrar.

Cajas registradoras

Métodos de pago

Renombrar un método no reescribe las ventas históricas (siguen con el nombre viejo en los reportes).

Operadores y PIN

Cada apertura de caja y cada venta queda firmada por un operador. Rol admin: puede emitir NC y cerrar caja; cajero: solo vende.

Balanza (productos pesables)

Códigos EAN-13 de balanza etiquetadora (Kretz/Systel): prefijo + PLU (5 dígitos) + valor (5 dígitos) + verificador. Cargale el PLU a cada producto pesable en su ficha — y si ese producto puntual usa un formato distinto al general (por ejemplo, la mayoría pesa por kilo pero algunos vienen con precio fijo, como una tableta de chocolate), elegilo ahí mismo, en la ficha del producto.
